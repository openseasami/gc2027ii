# M-C対象の比較照合（2026-10-29）

ユーザーの変更指示に従い、実機計算との照合と公式本文の取得を判定条件から外しました。非公式サイトの一覧を比較して対象を決定しています。公式による認定を意味するものではありません。

**231種族、356形態**を対象にします。通常・リージョン等の登録形態267、メガ82、戦闘中の参照形態7です。参照形態は、その状態から独立して選出できるという意味ではありません。

元の386候補から次の30レコードを選択肢から外しました。

- 外見だけが異なる26件：ビビヨン19、マホイップ7。種族値・タイプ・特性・重量・習得候補・主要技が代表形態と同一であることを確認し統合。**使用不可と判定したわけではありません。** 旧JSONは同じ計算条件を保って移行します。
- M-Cの根拠がない4件：メテノ（りゅうせい）、ウッウ（うのみ）、ウッウ（まるのみ）、コオリッポ（ナイスフェイス）。元種族が比較したM-C/登場一覧に存在せず、Showdownの戦闘中形態という理由だけで対象にしていた状態を修正。現在のビューアでは選択・計算しません。

## 照合したサイト

1. [Serebii：登場一覧](https://www.serebii.net/pokemonchampions/pokemon.shtml)と[M-Cの追加対象](https://www.serebii.net/pokemonchampions/rankedbattle/regulationm-c.shtml)
2. [ポケモンチャンピオンズ育成考察Wiki：M-C使用可能一覧](https://champions.pokewiki.net/レギュレーションM-Cの使用可能ポケモン)
3. [Bulbapedia：Regulation Set M-C](https://bulbapedia.bulbagarden.net/wiki/Regulation_Set_M-C)

総数は形態の数え方が違うため、その数字だけでは決めていません。名前・図鑑番号・リージョン・性別・メガ・戦闘中形態を正規化し、**形態そのものの掲載**と**元種族の掲載**を別の根拠として保存しました。

通常は複数サイトで明示された形態を採用。一覧が形態をまとめている場合は、他サイトの明示形態、独立した複数サイトでの元種族の掲載、Champions用の形態ページを組み合わせます。この場合を「複数サイトが同じ形態を明示した」とは記録していません。Showdownだけを根拠にした採用はありません。

## 相違と補完

- Bulbapediaの取得一覧にはドドゲザンがありませんでした。育成考察WikiとSerebiiに掲載されているため残しました。一サイトの不掲載だけを使用不可の根拠にしません。
- フラエッテの総称を通常の花へ広げず、育成考察Wikiの「永遠の花」と[SerebiiのChampions専用ページ](https://www.serebii.net/pokedex-champions/floette/)で確認。通常フラエッテは追加していません。
- メガニャオニクスは一部サイトが一見出しにまとめています。育成考察Wikiの♂♀と[RotomLabsのChampions・メガ♀ページ](https://rotomlabs.net/dex/champions/meowstic/mega-female)等で補い、両方を残しました。
- ポットデス、イッカネズミ、ヤバソチャの特殊形態はSerebiiの各Champions図鑑の形態欄で補完。元種族のM-C掲載と特殊形態の存在は別の証拠です。
- ポワルン、ギルガルド、イルカマン等は戦闘中の参照形態と区別。ミミッキュ（ばれた）とモルペコ（はらぺこ）はSerebiiのChampions図鑑で形態変化を確認しています。
- サイトの能力値に相違があっても、自動で数値を上書きしていません。残した356件の計算入力を元版と照合し不変を確認しました。

## 一覧・再現

`reports/MC_ROSTER.csv` が対象356件、`MC_ROSTER_AUDIT.json` が386件すべての採否と形態別根拠です。`reports/mc-roster/` に取得日のある出典と、名前・ID・行番号などの事実データを保存。元記事全文は再配布しません。

開発環境では `npm run audit:roster` → `npm run data` → `npm test` で再現します。直接HTTP取得は403だったため、許可された検索サービスで取得した本文を使いました。取得できていない資料を確認済みにはしていません。
