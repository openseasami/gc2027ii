# v8の解析とv9の変更

元のHTMLを `source/GC2027II_Viewer_v8.html` として保持しました。v8には採用候補120件、DEX120件、技261件、メガ46基礎種のまとまり、持ち物日本語対応107件がありました。採用率の出典・集計日は記載されていませんでした。

v8は種族と能力ポイントをブラウザ保存し、対面・メガ・画像選択・控え・天候・フィールド・ランクを備えていました。ダメージ計算は複数補正をまとめて端数処理し、性格・特性・持ち物・16乱数・範囲補正を十分扱っていませんでした。登録技4つ等の事前設定も保存していませんでした。

v9では次を変更しています。

- Champions専用の計算モデル（@smogon/calcの世代0）を採用。通常第9世代計算を流用せず、レベル50・能力ポイント・性格・補正順序・16乱数・複数回攻撃を計算。
- 初版ではShowdown由来の386候補を収録。2026-10-29版では非公式サイトを比較し356形態（メガ82）へ限定。全国図鑑全体の流用ではありません。
- 最大6体に4技・通常特性・持ち物・性格・ポイントを保存。対応ストーンと形態、同種・同じ持ち物の重複、ポイント上限を検証。
- 登録欄を折りたたみ、分析条件→与ダメージ4対面→被ダメージ4対面→詳細・控えの順に整理。旧来の暗色、味方青・相手赤、画像、タイプ色と技名を維持。
- 相手の配分・特性・持ち物を仮定ごとに比較し、通常は最大3種類、残りを詳細へ。同値を重複排除。統計のない割合や先発ペア率を生成しません。
- 手動ランクと場を優先。HP満タン・低HP・発動済み特性を参考条件として明示。現在HP・履歴・AI推奨・ターン進行は追加していません。
- JSON書出し・検証付き読込・直前保存への復旧、v8移行補助版を追加。
- 346画像をHTMLに内蔵。画像共用形態は名前で識別できるよう表示。CDNを必要としません。

v8の割合データは原本・参照ファイルに保持しましたが、信頼できる集計資料を確認できないため画面では「統計未取得」とし、確定した採用率として表示していません。

2026-10-29の変更は、対象一覧の絞り込み、外見差のJSON互換移行、対象外の元保存の書出し、確認状態の文言です。計算エンジン・残した種族値等・UIレイアウト・JSONバージョンは維持しました。実機計算・公式本文取得はユーザー指示で判定条件外としました。

てだすけ・バー対応：4受け手の独立ON/OFFを攻撃見出しへ追加。同一攻撃者の2対面と控えへの計算を共有し、控えの攻撃者は補正なし。最大HP基準の最小・最大ダメージバーを追加。変化技は全計算欄から除外し、登録と下部の技候補を維持。PCの配色・画面幅・相手2体横並び・JSON形式・数値データを維持しました。
