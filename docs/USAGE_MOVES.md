# 形態別の技採用率・折りたたみ・色（2026-10-30）

## 参照元

今回は技採用率の参照元を1サイト、PokéKitに統一しました。

- 公開データ: https://poke.itlibra.com/opendata/usage-champions.json
- データ説明・再配布条件: https://poke.itlibra.com/ja/opendata
- 集計元表記: Smogon / Pokémon Showdown（集計元）・PokéKit（整形）
- 対象: Champions VGC reg.MC、ダブル、2026年9月、レーティング基準1760、1,631,943戦
- 取得日: 2026-10-30 JST。Web取得サービスが返した行番号付きJSONを全27,619行取得し、欠落なくJSONとして構文解析して保存しました。ゲーム実機や公式ランクの統計ではありません。

異なるサイトとの比較・優劣判断は行っていません。元の種族値・習得技データへこの統計の能力値を上書きしません。公開データのスナップショットを同梱し、利用中のネット通信や自動更新は行いません。集計月は画面に明示します。

## 相手の攻撃技

種族・形態の完全一致IDで参照し、変化技を除いた攻撃技を採用率の降順に並べます。同率は元の掲載順を維持。1～5位を通常表示し、6～10位は通常閉じた欄に計算済みの数値・バー・詳細を置きます。てだすけ等で再計算するとき、同じ対面の展開状態は維持します。味方の攻撃技は従来どおり登録した最大4技です。

通常ガブリアス、メガガブリアス、メガガブリアスZは別レコードです。メガガブリアスZの通常表示は、パワージェム81.7%、だいちのちから53.7%、りゅうせいぐん52.5%、かえんほうしゃ52.5%、りゅうのはどう51.2%。じしん1.5%は攻撃技7位の折りたたみ欄です。通常形態のデータを流用していません。

相手の場・控えの攻撃、場から味方控えへの攻撃で同じルールを使います。下部の技採用率一覧には変化技も残します。相手がその技を実際に登録していること、同時に5技以上持つことを意味しません。

## 公開データの上限

元サイトは上位150形態、それぞれ変化技を含む上位10技のみを公開しています。356形態中150形態に技統計があり、206形態は「未取得」と明示します。通常や別メガから補完しません。

150形態中、攻撃技5件以上は128形態、6件以上は105形態です。残り22形態は攻撃技が1～4件です。元の10技に変化技が含まれるため、今回の公開分ではどの形態も攻撃技10件には達しません（最大9件）。未掲載の技・割合を捏造せず、掲載件数を各対面に表示します。「10位まで」は掲載範囲内の上限です。全形態に必ず攻撃技10件を供給したとは判定しません。

## 色と計算

技名の背景と同じ18タイプの配色をバーの内部に使います。スキン系・うるおいボイス・天候等で技タイプが変わった条件は、計算後の実際のタイプでバーを着色します。数値・バー幅は同じ計算結果を参照し、最小値を塗り、乱数幅を斜線にします。幅は100%で止め、超過数値は維持します。

攻撃する側で縁取りを分けます。味方→相手は青、相手→味方は赤。対面カード・見出し・技ボタン・数値・バー外枠・詳細欄・6位以下欄・てだすけボタンを対象にし、控えの計算でも攻撃側を基準にします。技のタイプ色とは別の情報です。

計算エンジン、種族値、パーティ保存形式、既存登録データは維持しました。条件依存で未計算だった技は、採用率が高くても未計算のまま明示します。全仕様のcompletion:falseを維持します。

## 検証

tests/usage.cjsで356形態全件の完全一致参照、150形態の公開値と順位、通常/メガ/Z分離、未取得の別形態へ流用しないこと、変化技の保持・除外、配色を検証します。既存の種族値・単発・連続技・素早さ・てだすけの独立照合も再実行します。

tests/usage_browser.pyは実Chromium・実Edge Linuxで、各2対面の5技、折りたたみ・展開・てだすけ再計算、控え、実際のCSS色、うるおいボイスのタイプ色変更、未取得表示、JSON不変を実操作で確認します。tests/artifact.pyで実ZIP再展開後も同じ試験を行います。実行結果はUSAGE_RESULTS.json・BROWSER_RESULTS.json・ARTIFACT_BROWSER_RESULTS.jsonを参照してください。Windows実機とfile://直接起動は未検証です。
