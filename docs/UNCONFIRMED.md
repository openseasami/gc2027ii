# 未対応・未確認と対象外

## 改訂した判定条件

ユーザー指示により、実機計算との照合と公式本文取得を判定条件から外しました。今回のM-C対象絞り込みは非公式サイトの比較で判定します。両項目を保留理由にはしません。全仕様のcompletion:falseと、今回範囲のscopeCompletion:trueを区別します。

対象は231種族・356形態。元種族の根拠がない4形態を対象外、外見差26件を代表へ統合しました。詳細はMC_ROSTER.mdとMC_ROSTER_AUDIT.json。非公式資料の改訂で対象が変わる可能性はあり、公式認定を主張しません。

## データ・表示の制約

- 1形態はdamage-calcに独立の別名がなく、Showdownの確認可能なデータを上書き指定して計算します。2130種族値の二実装比較とは別枠です。356形態の能力値式は全件比較しています。
- 外見差26件は代表形態へ統合。通常選択肢の英語装飾ラベルはなくなりました。旧JSONは技・配分等を保持して移行します。
- 技はPokéKit公開データ（2026年9月M-Cダブル）を150形態分取得。残る206形態は未取得です。変化技を含む上位10技までの公開なので、攻撃技5件未満は22形態、全件で攻撃技10件には達しません。未掲載分は補完しません。通常・メガの別IDを維持します。元v8の出典不明の割合は使わず、特性・持ち物・先発ペアの採用率も今回の画面表示対象として検証していません。
- 相手配分は代表条件であり全配分の上限下限でも全組合せ探索でもありません。能力・持ち物・隣接特性の完全な同時分布は求めません。
- 特性は `reports/ABILITY_COVERAGE.json` に個別の対象・テスト証拠・未検証範囲を記録。モデルに対象所有者のないものを無理に有効な組合せにはしません。

## 計算を確定しない条件

- HP依存威力・被弾回数・ひんし数・PP・直前の行動等を要する一部技は「未計算」。機械可読一覧は `reports/UNCONFIRMED.json`。
- やけっぱち・じだんだは威力75／150の条件例です。前ターン履歴から成立を断定しません。
- しおふき・ふんか等はHP満タンの例。HPを入力・追跡しません。マルチスケイルは有効／無効、低HP火力は発動条件別の例です。
- トリプルアクセル・ネズミざん等は各ヒットの16乱数を独立計算し全命中例を表示。命中確率・途中外れ・途中KO・接触反応等は未認証。連続命中による持ち物消費・能力変動も完全再現しません。
- ばけのかわ・物理攻撃に対するアイスフェイスの初回防御は未対応。消費後の形態で参考計算します。タスキ・がんじょうを含め生存からの確定KOは表示しません。
- シードの消費・登場時能力変化は推定せず入力ランクを優先。シード消費で威力・成否が変わる技は未計算です。
- 2体対2体の盤面を仮定した範囲補正です。単体しか残っていない盤面・守る等の成否を推定しません。
- 素早さはランク0、麻痺・おいかぜ等なしの候補。かるわざ等は条件付き候補。TRは参考比較を反転しますが、技の優先度・同速・全行動順の判定ではありません。
- 数値比較には技の効果を単独検証するため習得組合せとは切り離した固定例も含みます。計算一致は公式使用許可の証明ではありません。
