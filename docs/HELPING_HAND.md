# てだすけ・ダメージバー・変化技の表示（2026-10-29）

今回記載された変更を実装しました。参照されている「前回のUI改善」の追加仕様は、この会話で確認できないため、現在のPC向けレイアウト・色・登録データを維持しています。

## 操作

「味方が与えるダメージ」「相手が与えるダメージ」の攻撃者見出しに、味方A/B・相手A/Bの4つの「てだすけ OFF／ON」があります。同じ攻撃者の2対面をまとめて切り替え、ON時は「てだすけ補正中」と表示します。

各ONは独立した参考条件です。両方をONにしても、同一ターンに両方が攻撃できることを示しません。使用者の選択・技選択・実際の行動順を推測する入力は追加していません。

対象ポケモンの入替、JSON復元、条件初期化では設定をOFFにします。同じ個体のメガ前後では保持します。設定は一時的な分析条件で、チームJSONの保存形式・バージョン9は変更していません。

## 計算

既存のChampions専用エンジンにある `attackerSide.isHelpingHand` を、計算ごとの攻撃者に一度だけ渡します。威力補正は1.5（内部比6144/4096）で、特性・持ち物・場・ランク・火傷・急所との補正順序と端数処理も既存経路を使います。元の技威力や最終ダメージを手動で重ねて1.5倍する処理はありません。

独立比較では[ShowdownのHelping Hand処理](https://github.com/smogon/pokemon-showdown/blob/1242c1e2d9763ba5b85d33f13aecb89bae19ae3d/data/moves.ts#L8576)を受け手に一度設定し、各16乱数を照合しています。威力の補正なので、固定ダメージ等は増えません。無効な攻撃が有効になることもありません。

場の攻撃者から控えを狙う参考計算には同じ設定を適用します。控えが攻撃者の場合は補正なし。防御側や隣のポケモンのONを攻撃者へ流用しません。

## バーと変化技

バーの全幅は各条件の対象最大HP100%です。濃色は最小ダメージ、斜線は最小～最大の乱数幅。100%を超える範囲は端で止め、数値はそのまま表示します。0ダメージは長さ0です。現在HPを入力・追跡しているものではなく、確定KOを示しません。

ダメージ数値とバーは同じ計算結果から同時に描画し、てだすけ・天候・フィールド・ランク・火傷・メガ形態の変更に追従します。未計算の技を0ダメージのバーとして表示しません。

登録した「てだすけ」「まもる」などは保存できますが、与ダメージ・被ダメージ・控えの計算欄には表示しません。下部の技候補一覧は変化技を含む元データを保持します。採用率を取得済みと偽る変更はしていません。
