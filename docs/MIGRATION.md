# v8からの移行とバックアップ

移行前に元のv8 HTML・保存済みJSONをコピーして保管してください。旧キーの削除や旧対戦支援システムのデータ変更は行いません。

## 同じHTTP接続先の場合

同じブラウザ・同じプロファイル・同じオリジンでv9を開くと、v9の保存がない場合だけv8の登録種族と能力ポイントを読み込みます。対象キーは `gc2027ii-viewer-own-team-v5`、`gc2027ii-viewer-own-sp-v8`、旧EVの `gc2027ii-viewer-own-ev-v6` です。種族の保存がなくポイントのみ保存されていたv8初期2体も移行します。旧EVはv8と同じ換算を行います。

v8は技・特性・持ち物・性格を保存していません。これらは初期値になるため、必ず登録画面で確認・訂正してください。移行後にJSON出力し保管してください。v8に存在する種族が収録候補にない、重複、ポイント範囲外などの場合は移行を中止し、元の保存を保持します。

## file://・別オリジンから移る場合

ファイルの別パス・別ファイル名や別ポートへ移ると、localStorageが共有されない場合があります。

1. **元のv8 HTMLを別名でバックアップ**します。
2. `migration/GC2027II_Viewer_v8.html` は元のv8にJSON出力ボタンだけを追加した補助版です。元のv8を使っていた**同じパス・同じファイル名**に、この補助版のコピーを配置します。別名で開くだけでは元データを読めない場合があります。
3. 元と同じブラウザ・プロファイル・接続方法で開き、「v9移行用JSON出力」を押します。取得したJSONの種族とポイントを確認します。元のHTMLバックアップは保持してください。
4. v9を起動し、「JSON読込」からそのJSONを選択→内容確認→「この内容を反映」。登録項目を補完してv9のJSONを出力します。

この管理環境はfile://を禁止しているため、同じHTTPオリジンで補助版の出力・v9への読込を実ブラウザ検証しました。Windowsでのfile://保存領域の共有自体は未確認です。データが表示されなければ空の内容を上書き保存せず、元のv8に戻してください。

## バックアップと復旧

- 「JSON出力」で出したファイルをPCの別フォルダにも保存します。登録変更・ブラウザ更新・別PCへの移行前に出力します。
- JSONはパーティ6枠の種族・形態・技・特性・持ち物・性格・能力ポイントのみです。ランク・相手・天候等の一時的な分析条件は含みません。
- 読込は検証→プレビュー→明示的な反映です。不正形式・不正ポイント・あり得ないメガ持ち物等は反映しません。
- 「直前の登録に戻す」は最後の保存前1世代です。長期バックアップの代わりにはなりません。
- ブラウザへの保存に失敗すると表示します。その場合も画面の変更はJSON出力で保管できます。
- 旧対戦支援システムのJSONは別形式です。ビューア用のJSONとして読み込みません。
