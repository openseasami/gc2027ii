# GC2027II ダブルバトル情報ビューア v9（てだすけ・バー対応）

v8を基準にした、大会前の練習・対策と大会後の分析用の独立した情報ビューアです。旧対戦支援システムとは別のプロジェクトです。対戦中の使用許可を示すものではありません。

**てだすけ・ダメージバー・変化技除外と既存回帰の検証は合格。** ユーザー指示で実機計算・公式本文取得を判定条件から外しました。231種族・356形態に対象を限定しています。全仕様の `completion: false` は維持し、今回範囲の `scopeCompletion: true` と区別します。詳しくは `docs/MC_ROSTER.md`。

## 起動

配布ZIPをすべて展開し、Windowsでは `start-viewer.cmd` を起動してください。Python 3が必要です。Microsoft EdgeまたはChromeで `http://127.0.0.1:8766/GC2027II_Viewer_v9.html` を開きます。終了はサーバー画面で Ctrl+C。Mac/Linuxでは `python3 launch-viewer.py`。表示先はこのPC内のみです。

HTMLには計算コード・データ・画像を埋め込み済みです。初回にPythonが利用できる状態なら、その後は外部インターネット接続なしで動きます。HTMLの直接ダブルクリック起動は、この管理環境では `file://` がブラウザポリシーで遮断されているため未検証です。検証済みのローカルHTTP起動を使用してください。

## 使い方と保存

1. 上部の「自分の6体を事前登録」を開き、種族・形態・技・通常特性・持ち物・性格・6能力ポイントを設定します。各0～32、合計66以下。メガには対応ストーンを登録します。初期2体はサンプルです。
2. 登録欄を閉じ、味方の登録枠2体、相手2体と形態を選択します。相手の配分・特性・持ち物を入力する必要はありません。
3. A/B/C/Dの現在ランク、各個体のやけど、天候・フィールド・TRを変更します。攻撃者見出しの「てだすけ OFF／ON」で各受け手を独立に指定できます。与ダメージ4対面・被ダメージ4対面の数値とバーが更新されます。バー全幅は対象最大HP100%、濃色は最小値、斜線は乱数幅です。
4. 通常表示は最大3条件です。「全条件・急所参考・16乱数」で仮定の全文・実ダメージ・各打撃の16乱数を確認できます。下部に素早さ候補・統計の確認状態・控え比較があります。
5. 登録変更はブラウザへ保存されます。「JSON出力」でファイルにバックアップしてください。「JSON読込」→内容確認→「この内容を反映」で復元できます。誤読込後は「直前の登録に戻す」も使えます。

保存先は**ブラウザ・プロファイル・接続先のオリジン**ごとに異なります。`localhost` と `127.0.0.1`、ポート違い、旧公開版では共有しません。プライベートモード・履歴削除・ブラウザ変更前にはJSONを出力してください。分析中のランク・相手・場は保存対象ではありません。

割合は「命中時のダメージ／その条件の最大HP」です。相手の0ポイント無補正は基準例であり、実配分の確定値ではありません。HP満タン・低HP・発動済み特性・やけっぱち等は条件例です。連続技は全命中例で、命中率・途中終了・途中KO・反応効果を保証しません。確定KOや行動推奨は表示しません。素早さはランク0での参考範囲で、全行動順を再現しません。

## 資料

- `docs/HELPING_HAND.md`：4体のてだすけ・ダメージバー・変化技の扱いと検証
- `docs/MC_ROSTER.md` / `reports/MC_ROSTER.csv`：対象と採否の根拠
- `docs/VERIFICATION_REPORT.md`：実行済み数値・実ブラウザ試験と範囲
- `docs/ABILITIES.md` / `reports/ABILITY_COVERAGE.json`：指定特性の候補・効果・テスト証拠
- `docs/UNCONFIRMED.md`：未対応・未確認・対象外
- `docs/MIGRATION.md`：v8の移行とJSON保管
- `docs/V8_CHANGES.md`：v8解析・変更点
- `docs/SOURCES.md`：一次資料の取得状況、計算・データ出典
- `docs/DEVELOPMENT_CHECKPOINT.md`：再現手順と残件
- `SHA256SUMS.txt`：ZIP内ファイルのSHA-256。ZIP自体のハッシュは隣接の `.sha256` ファイル。

通常起動にNode.js、npm、Showdown、ネット接続は不要です。開発・再検証の方法はチェックポイントに記載しています。
